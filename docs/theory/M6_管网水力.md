# M6 管网水力（执行中）

书稿第 4.1.3 节式 4.4、4.5：管内速度 $v=Q/A$，动压 $\rho v²/2$；沿程损失 $\lambda(L/D_h)\rho v²/2$，局部损失 $\sum\zeta\rho v²/2$。圆管 $D_h=D$，矩形管取水力直径 $D_h=2ab/(a+b)$。湍流 Colebrook 隐式式用 Brent 求解，Altshul 为可选近似；层流 $64/Re$，过渡区在层流和 Re=4000 湍流结果间插值（仅作近似，需不确定性复核）。空气密度取 M0，黏度采用 NIST TN 1887 第 258 页关联式。

`DuctSegment` 支持圆管和矩形管；`network` 对给定风量的枝状及分风箱路径累加共享管段，找最不利环路；以较大压损为分母计算不平衡率。`balance_parallel_flows` 对共同入口及同压出口的树状并联路径求解各支路自然流量与压降，区分共享干管，求解流量守恒和等压；无风阀控制、不同末端压力、反向流或环状网。风机工作点将各段设计流量按同一比例缩放，仅适合固定比例网络，不能替代耦合风机的并联自动平衡；风机效率检查需要用户给出的工作点效率及最高效率，不代替效率曲线。`fan_allowance` 必须明确声明 `flow_unit='m3/s'`，工程单位在输入层转换；仅凭无量纲数字无法检测使用者错误声明单位。

`data/duct_fittings.yaml` 列有 Purdue 公开教材第 7 页锐边入口、排入大空间出口、法兰普通 90° 弯头的典型系数，并保留示例条件 A7 示例值；前者为圆管通用典型值，并非适用于任意住宅风管的设计值。用户须核对几何、雷诺数和参考断面。A7 示例值几何未知，标记“假设，需作者确认”并采用 ±20% 敏感性分析。2.5 节没有数值设计例题，`ex2-09` 自拟参数而非原书结果。书稿式 2-24 的水力半径平方导致量纲问题，已列入差异清单。
