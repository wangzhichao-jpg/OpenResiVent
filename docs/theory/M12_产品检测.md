# M12 产品检测数据处理

`exchange_efficiency` 将送风侧实测传递量除以最小干空气质量流量乘两股入口状态差，分别取温度差、含湿量差及湿空气焓差，得到显热、潜热及全热效率。等风量时退化为送风状态变化与入口状态差之比。此为本工单给定的归一化定义，与 ASHRAE 84 / EN 308 的换热器有效度思路相关；未核对标准原文的完整实验修正条款，不冒称符合完整标准试验。对不平衡风量、泄漏、冷凝、风机热等，需要按相应试验方法单独修正；计算结果可能超过100%，不强制截断。湿空气焓采用 M0 的 ASHRAE Fundamentals 2017 公式。

风机同密度、同几何相似定律为 Q₂/Q₁=r、Δp₂/Δp₁=r²、P₂/P₁=r³；不保证换速后仍在真实产品曲线上。单位风量耗功率 W/(m³/h) 和 SFP W/(m³/s) 两者相差3600倍。

净化能效依据 JGJ/T 440-2018 第5.2.6条转述，按风量乘一次通过颗粒物效率除以电功率计算，单位 m³/(W·h)。单向流节能级≥5、合格级≥2；双向流节能级≥3、合格级≥1.25，界限等于时取较高级。实际受测试工况、粉尘和功率边界影响。

`ex6-06` 为假设演示数据，不代表真实检测设备。开发方案和工单将其关联书稿6.4节，但目前只读书稿6.4节实际是室内风速测试，未发现相应产品检测原文；此处如实记录，算例不冒称书稿已给出数据，待作者确认。
