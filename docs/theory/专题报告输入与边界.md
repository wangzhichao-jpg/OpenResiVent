# 竖井安全与调试运维报告

命令：`resivent report cases/reports/shaft_example.yaml --type shaft --format docx`；`resivent report cases/reports/commissioning_example.yaml --type commissioning --format docx`。示例均为假设，默认输出 `build/reports/`，可用 `--out` 更改。报告包含输入哈希、软件版本和 Git 状态；扫描正文、表格、页眉页脚的管理用语和内部编号。专题报告还拒绝常见机构后缀和“品牌”字样；自动后缀检查不能穷举所有机构及品牌，仍须人工逐项复核，不应输入此类名称。

竖井报告组合 M3 `ShaftConfig` 和 M7 `p2_dwelling`，逐层列示 M3 结果，底层没开机时明确不判定300 m³/h；补风方案来自 M7 独立住宅工况，二者不是同一个联立模型。15 Pa 为可配置示例提示阈值而非安全限值；倒灌或低排风不能从本报告单独判定健康风险，需专项论证与现场检测。

调试报告允许合成演示参数（示例文件）或把 `acceptance.records` 设置为 M11 逐条记录。记录含 `time`（ISO 时间）、`outdoor_pm`、`indoor_pm`（kg/m³）、`indoor_co2`（体积分数），30天十分钟数据；`spot_records`、可选 `retest_records` 含 time、indoor_pm、indoor_co2，首测45分钟及复测要求按 M11 校核。记录作为 YAML 输入的一部分并被输入 SHA256 覆盖；用户必须对外公开前去标识。该报告分别列风量偏差、连续监测双轨、检测法及 M7 联合工况；监测设计轨按自然日/小时窗口判定，验收轨使用最不利五日的计算，不能相互替代，门窗及运行工况须现场核查。

滤网压差达到初始两倍、芯体清洗后相对衰减超过20%分别是研究和书稿建议，不是本程序声称的强制标准；清洗方法须符合实际设备说明书，断电操作，未经许可不得水洗纸基膜。
