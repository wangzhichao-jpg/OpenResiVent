# M7 户内压差与补风

本模块调用 M2 稳态等温多区网络，内部单位 SI。`Dwelling` 提供两、三、四卧室模板（另含起居室、卫生间和开敞或封闭厨房）。各室外墙缝隙系数按相同权重分摊：Cᵢ=n₅₀V/(50ⁿN)，n₅₀ 单位 s⁻¹；总 50 Pa 泄漏量保持不变。实际分摊应按外墙和门窗状况测定；居室体积等分、室内各门缝 0.015 m²、附加过流口 0.005 m²、Cd=0.6 为 D9 假设，非标准或实测值。

新风机送排风、厨房油烟机和卫生间排风扇均用理想定流量，设备能力范围由使用者核对；不计算油烟机随背压变化。正常运行新风机排送比及是否在 80%～90% 区间单独输出，对照 JGJ/T 440-2018 第 3.0.3 条；联锁时的实际临时风量另列，不将临时状态误作正常设计值。天然补风孔口、机械补风、新风联锁关排风或加送风均可组合；各设备和补风口可分别设置在有效房间，开敞厨房与起居室为同一区；加送风联锁额外增加相当于油烟机的设定风量，须核实风机能力。开敞厨房并入起居室；燃气具仅取所在房间负压提示，默认阈值 15 Pa（书稿 5.3.2 及方案 M7），并非燃气安全认证。其他室内源、风压、烟道倒灌与设备动态未模拟。

输出各室表压、各门压差及气流方向、设备流量、自然补风量、户门压差对应的保守开启力，以及联合工况和测量项。户门按 0.9×2.1 m、把手距门边 0.06 m、无闭门器假设；公式见 示例 A10，ASHRAE / NFPA 92 原文页码待核。使用压差绝对值计算不利方向开门力，不区分门扇开启方向，未考虑门锁、摩擦和开启动态。联合工况须以现场门窗状态、风机性能及仪器验证，不代替标准要求。
