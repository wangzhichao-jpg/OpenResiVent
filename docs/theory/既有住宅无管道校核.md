# 既有住宅无管道设备初筛

以 JGJ/T 440-2018 第4.2.2条的换气次数法与 CO₂ 法取较大值作为房间需求。CO₂ 排放和全户人均居住面积需用户确认。设备有效风量示例为设备额定风量乘有效换气率与台数；有效换气率0.7与0.8是**假设，需作者确认**，不是产品实测值，也不声称是 QB/T 5580-2021 原文的换算式。暂未获得该标准原文或足以核验试验定义及具体取值的公开资料，须以相同测试边界、实测结果和标准原文复核。额定风量可能受压差、工况影响。

第4.3.7条第1款为一房间宜设置一套无管道系统，第2款为室内送排风不应短路；0.9 m 间距的几何预警还借用了第4.4.4条送排风口间距要求，不以间距单独证明实际短路。第4.3.3条涉及分户式新风系统应用条件，不是单房单设备条文。房间有效风量和气流组织均需现场复核。
