# 书稿计算片段体例规范 v2

适用于软件生成的计算片段；题设和作者讨论不由软件改写。书稿源文件始终只读。

1. 每个片段依次使用四个加粗段落标签：**已知条件**、**计算**、**结果**、**条文对照**。没有适用条文时写“本例不涉及条文对照”。
2. 已知条件先以一句话说明题设，然后列“参数 / 符号 / 数值 / 单位 / 来源”表。来源使用书稿节号、标准条号、论文表号或“假设，需作者确认”，不得把假设写成实测。正式出版前全部待确认参数改为正式来源。
3. 计算段保留关键公式、代入式及关键中间值，不在正文列出完整逐路径、逐房间或逐层表。原有编号公式保留原编号，新公式不擅自编号。结果段列关键结论及适用边界，设计轨与验收轨不得混写。
4. 完整中间过程按章写入 `build/book_appendix/chNN_完整演算.md`，包含各算例的完整演算和计算结果。正文可提示“完整演算见附录 X”；附录序号由作者确定。文档站用户手册说明生成和查阅方法。
5. 正文最后一行固定为“本算例由 OpenResiVent v{版本} 计算，算例文件 cases/book/chNN/exN-NN.yaml”，版本取软件自身版本。
6. 来源待确认项通过 `tools/pending_sources.py` 从正文参数表逐项提取到 `build/待确认参数清单.md`；同名参数在不同房间分别计数。结果不得作为正式来源。
7. 构建副本及预览锁在 `build/`；成对标记外不改变书稿。示例与假设明确标注，必要时给出敏感性分析；软件计算不能代替作者复核或现场验证。
