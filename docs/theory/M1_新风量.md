# M1 新风量方法

按 JGJ/T 440-2018 第 4.2.1、4.2.2、4.2.3 条和 参考说明：用全户人均居住面积确定换气次数档位；每间卧室取换气次数法和 CO₂ 法较大值，启用 GB/T 18883-2022 或 GB/T 51350-2019 时再与人员法比较。起居室按住户总人数计算人员法，并与其换气次数法比较。卧室结果之和再加起居室结果，与全户换气次数法及启用时的全户人员法比较。最后按照 5.2.1 给风机选型风量增加漏风附加。

卧室和起居室计算中可能重复计入同一人员，这是标准房间法汇总口径，并非同一时刻全户人数。报告同时列出仅 440 与合并规则包的结果，不能以按人员合计推断为实时人数。CO₂ 计算仅在完全混合、稳态及无其他源汇假定下适用。偏离 440 标准室外浓度默认值的计算仅作为敏感性分析，不能自动等同于标准条件下判定。ASHRAE 和 EN 结果是公式比较，不等同于完整标准合规设计。
