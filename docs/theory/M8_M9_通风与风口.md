# M8、M9 自然通风、射流与风口

单开口按 CIBSE 简化式 $Q=C_dA\sqrt{gh\Delta T/\bar T}/3$；双开口 $A^*=(A_1^{-2}+A_2^{-2})^{-1/2}$、$Q=C_dA^*\sqrt{2gh\Delta T/\bar T}$。温度为绝对 K，$\Delta T$ 为正温差，假设两个开口流量系数相同且无机械通风。联合作用采用 M2 压力网络，热压实际密度与风压系数分别由节点和入口设定；不同密度时两路径体积风量不相等，质量流量守恒；与单一近似体积流量比较以两路径体积风量均值作为近似代表，入口、出口分别报告。旧版书稿第 28–30 页对照式采用 $Q_1=0.04A\sqrt{\Delta T h}$、$Q_2=0.15A^*\sqrt{\Delta T h}$；后者面积为双孔串联等效面积。0.04 和 0.15 是带单位 m$^{1/2}$/(s·K$^{1/2}$) 的经验系数，不是无量纲数。迎风面积 $A$（m²）时高度对照为 $H_c\approx0.3\sqrt A$、$H_k\approx\sqrt A$；高度系数按以米为单位的面积数值使用。相同几何条件下与 CIBSE 公式比较见自然通风验证文档。

射流按书稿 2.4.3 式(2-20)–(2-22)，仅主体段的理想自由圆射流近似；回流、浮力、墙面贴附及实际流场需现场或 CFD 核验。风口和新风口依据 JGJ/T 440-2018 第4.3.7、4.4.1、4.4.4条、GB 50736-2012 第6.3.1条做几何初筛，不替代完整设计；空间凹槽、天井、风向等复杂污染输运需单独评估。现行污染源水平或垂直分离是按输入选用的布局；分户式进排口方向与一般污染源分别判断。`outdoor_intake(..., matrix=...)` 接收源类型到 `{horizontal_m, vertical_m}` 的用户字典，当前不内置修订研究矩阵；该矩阵为用户提供的额外研究判据，不能冒称现行标准。

指标：本模块同时提供 $\gamma_{自然}=Q_{风帽}/Q_{同条件敞口}$ 和 $\varphi=Q_{风帽}/Q_{静态风帽}-1$；论文13式(6)的 $\gamma$ 实际为 $Q_{风帽}/Q_{静态风帽}=1+\varphi$，**不同于本任务的自然开口参照**。不可混用两种γ。正压竖井只能根据对应风速和图7a界限判断，不能绝对宣称所有正压下均无增益；高风速超过界限可能超过静态风帽，且特定论文模型与工程竖井有差异。
