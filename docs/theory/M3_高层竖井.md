# M3 高层竖井 v1

稳态多区压力网络，SI 单位；风机、各楼层住户、竖井、各层支管、止回阀和屋顶出口联立质量守恒。风机正向曲线为 $p=p_0-kQ^2$，以零流最大压力及额定点确定 $k$；书稿 5.3.1 所列普通型（600 m³/h，100 Pa，200 Pa）、常用型（1080，330，420）、高压型（1080，800，1000），并不代表实际产品的完整性能曲线。低于零流和超过自由风量时采用 `PolynomialFan` 的显式端点延拓，需警惕适用范围。

止回阀等级来自书稿 5.4.1 表 5-10：250 Pa 下单位面积漏风量良好 <100、中等 100～200、差 >200 m³/(h·m²)。代表值 74、150、300 m³/(h·m²) 中，74 为书稿 5.3.1 对相关研究[25]的公开示例，150 和 300 为 D9 假设。阀门按 250 Pa 漏风率幂律计算反流；正向开度系数、零开启压力、阀直径与指数均是假设，不代表实测产品。

竖井矩形段按水力直径 $D_h=4A/P$ 及实际截面计算 Darcy–Weisbach 阻力，摩擦系数 Colebrook；支管为圆管。每层高度、截面、粗糙度、支管尺寸、局阻、围护 n₅₀、容积、出口面积及流量系数、风压系数和设备使用分布等无可靠原始数值，均为可配置 D9 假设；示例敏感性及趋势见 `docs/verification/M3_趋势检验.md`。屋顶出口孔口代表静态风帽阻力，不模拟真实风帽的方向特性、变风量性能或倒流控制。

每层户内泄漏按 n₅₀ 幂律折算；各层竖井及室内节点分别按高度计算重力静压，外界风压施加于屋顶出口。输出竖井相对同高度室外压差和相对同层住户压差、运行楼层排风、非运行楼层反灌量及运行楼层排风标准差；室外同高度压力按室外参考点压力减去室外空气密度乘重力加速度和高差计算，原节点压力仅在 `_zone_pressures_pa` 内部字段保留。底层不运行时是否达 300 m³/h 为不适用。热压附加排风量为同一配置下室外温度改为室内温度后的差值（如风速非零，也包含由于室外密度改变引起的风压变化），非供热能耗计算。系统压力与风量可能受假设强烈影响，不能当作文献实测值或设计保证。

`scan_csv` 对楼层数、截面、同时使用率、风机和阀等级做全因子组合，随机分布用固定种子，CSV 使用中文表头及 m³/h 风量，含底层风量、非运行层最大倒灌风量及楼层、热压附加风量和顶层两类压差；底层未运行及全部楼层运行时，相关不适用列留空。工况失败直接报错，不跳过或伪造数值。本模块尚未涉及污染物、健康风险和团队原始数据。L3 对照与定性趋势独立记录在验证文件中。
