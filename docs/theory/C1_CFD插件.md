# C1 CFD 外部进程插件

模板和输入字典由本项目独立编写，不包含 OpenFOAM 源码或官方教程文件。`openresivent.cfd.template.create_room` 在新目录生成二维分块、三维矩形房间网格、两端墙面的矩形送排风口及 k-ε 稳态不可压缩字典，开口宽高、两端墙内中心位置、风量和网格级数可配置；只允许在用户自建案例路径写出，拒绝覆盖。默认送风口位于一端墙顶侧，排风口位于对侧墙顶侧或底侧。当前不支持其他墙面或非矩形风口；可选均匀内部热源通过冻结流场的被动温度标量计算（ρ=1.2 kg/m³、cp=1006 J/(kg·K)），不模拟热浮力与流场反馈，不可用于热源驱动流场或热舒适定量设计。`ser8-cfd-p304-thermal-1` 已实际检验100 W 被动热源方程可求解。

`submit` 仅允许 `~/data/research/cfd/openresivent/` 下案例，通过 `foam-job` 和系统用户单元调用外部 OpenCFD v2512；单元锁、状态及日志由工具负责。先网格及 checkMesh、再求解流场，复制最后时刻守恒面通量 `phi` 及 U 至标量初始时刻，防止从单元 U 重新插值导致通量不守恒，再求空气龄。源项及字典自行构造：稳态 `div(Uτ)−div(D∇τ)=1`，入口零龄，出口和固壁零梯度；`D=0.005 m²/s` 是统一有效扩散的演示假设，**不是逐格湍流黏度计算，也非已验证的湍流标量模型**。出入口相反方向倒灌边界、非稳态或温湿度输运需额外建模；非等温 M2 必须先定义与不可压缩 CFD 一致的流量基准，`from_network` 对质量流量和体积流量不平衡明确拒绝。

默认对流离散：动量 bounded Gauss linearUpwind，k、ε、空气龄 bounded Gauss limitedLinear；可显式选择一阶迎风。受限制格式在局部极值会降阶，需分别进行迭代和空间收敛检查。`postprocess.summarize` 使用单元体积加权求平均空气龄和中心位于0.1～1.8 m的呼吸区平均空气龄，名义时间常数 V/Q，换气效率复用 M11 的 τₙ/(2⟨τ⟩)。呼吸区以单元中心筛选，边界相交的单元未精确裁切。通量从守恒 `phi` 边界读入，若不可压缩同一密度，体积流量守恒等价于质量流量守恒。`read_vtk` 的 PyVista 是可选外部后处理环境，不作为 OpenFOAM 进程内接口；未安装时明确提示，不随仓库分发。`gci` 按等加密比、三解单调收敛条件计算 Roache 安全系数1.25的细网格 GCI，非单调或零阶次时拒绝给出误导性百分数；经迭代收敛后可另用三网格效率半极差描述振荡网格的不确定度，不等同 GCI。

初步试算 `ser8-cfd-p304-pilot-b`：1920 单元、checkMesh 通过、流场126次迭代收敛，标量线性方程相对残差约8.2×10⁻¹¹；进出口守恒误差约9.6×10⁻⁹。试算不代表网格独立性或工程验证。另一次 pilot-a 曾因未传递守恒 phi 导致通量不一致，保留作废；不能用其结果做验证。各任务日志在 `~/.local/state/ser8-cfd/jobs/`，案例均在 `~/data/research/cfd/openresivent/`。
