# C1 CFD 验证与边界

本文件的案例名和目录采用功能性中性标识；历史计算目录并未随文档改名或复制，重算时需将已授权的原始结果整理至相应新目录。以下数值来自原历史计算，不因改名而变化。

## 模型和许可

全部 OpenFOAM 计算通过 `foam-job` 启动用户 systemd 任务（`cfd-` 前缀），版本 OpenCFD v2512 固定镜像，GPL 软件只作为外部进程调用。网格、流场和日志不进仓库，位置为项目本地数据目录；用户单元日志位于本机状态目录。所有字典由本项目独立编写。空气龄为稳态 `div(Uτ)−div(D∇τ)=1`，送风τ=0、固壁及出口零梯度；冻结 RANS 流场，统一有效扩散 D=0.005 m²/s 为示例假设，非局部湍流扩散。计算先使用 `simpleFoam` k-ε，再用 `scalarTransportFoam` 的单位源项；读取求解器守恒面通量，不重新插值替代。

## 示例 二阶离散复核（R33）

模板默认速度 `bounded Gauss linearUpwind grad(U)`，k、ε及空气龄 `bounded Gauss limitedLinear 1`；保留一阶选项。速度线性迎风使用上游梯度提高空间阶次；限制线性减少非物理振荡，但局部极值处会退化为低阶，不能将其称为全域严格二阶。有限体积通道以 `Gauss linearUpwind grad(T)` 独立求解、标量松弛0.3；与先前仅解一次相比需迭代修正。`cfd-second-order-channel-linear` 中心首排0.0250 s、第二排0.0750 s、中间3.0250 s、末排6.0000 s；除首排外最大相对误差0.4184%，主要出现在出口零梯度边界附近。首排理论0.025 s，本例也符合；一阶旧结果首排0.050 s、末排6.000 s，旧出口准确是数值误差抵消。

早期二阶值因标量未收敛已作废：上排843.420/829.030/803.026 s、下排609.011/618.744/595.942 s；不可将早期差值作为网格误差。续算使用压力松弛0.15、动量及湍流0.3，空气龄由0.3调整为0.6并独立求解，冻结已收敛流场，记录每10步监测。新结果：

## 活塞流解析验证

`cfd-first-order-channel-1`：通道 L=3 m、截面1×1 m²、均匀给定 U=0.5 m/s、D=10⁻⁹ m²/s；120×4×4=1920单元，出口16面平均空气龄 **6.000000 s**，解析 L/U=6 s，相对差小于0.01%。checkMesh `Mesh OK`，标量线性残差2.18×10⁻¹⁵。本例是给定均匀流的标量方程验证，不是用层流求解器重现入口发展流动。

## 卧室两布置：网格与收敛

示例假设：房间4×3×2.5 m，Q=0.05 m³/s，开口0.5×0.5 m，进出口位于对侧墙上；上送上排与上送下排。`first-order-{upper,lower}-{1,2,4}` 三个相邻网格尺寸分别0.25、0.125、0.0625 m；单元数1920、15360、122880。中细网格初次执行至1200步部分未满足残差门槛，故分别保留原目录，并以其1200步场为初值另建 `-r2` 案例续算，不覆盖原结果。

上送下排（1、2-r2、4-r2）：全室平均空气龄628.371、619.713、616.833 s；单调收敛，以细/中和中/粗加密比均为2，观测阶 p=1.5883，细网格 GCI=0.2907%（安全系数1.25），外推值615.398 s。细网格呼吸区平均648.471 s，V/Q=600 s，η=48.64%，进出口通量守恒相对差3.16×10⁻⁹；其细网格流场达到预设残差门槛。

上送上排（1、2-r2、4-r2）：全室平均空气龄828.535、809.119、803.646 s；单调收敛，观测阶 p=1.8270，细网格 GCI=0.3341%，外推值801.498 s。细网格呼吸区平均847.809 s，V/Q=600 s，η=37.33%，进出口通量守恒相对差5.72×10⁻¹⁰。中、细网格续算分别在1520和3615次迭代达到预设残差门槛；其初次1200步的813.892 s、812.706 s因未达残差标准不作 GCI 输入。

各算例 `log.simpleFoam` 末尾的求解 CPU 时间（s，含并发竞争，仅供复现参考）：粗上/下0.34/0.39；中网格上/下初次28.83/28.28、续算36.29/68.03；细网格上/下初次212.92/208.35、续算549.08/46.40。所有网格 `checkMesh` 显示 Mesh OK，局部空气龄字段保存在 CFD 目录的 VTU 中。两种布置细网格空气龄及效率由 `tools/cfd_first_order_postprocess.py` 重算，M11 函数用于相同效率公式。
