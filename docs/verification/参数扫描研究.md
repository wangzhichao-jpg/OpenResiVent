# 参数扫描研究

下述输出目录是按功能命名的新位置；历史结果未自动迁移，按原定义重算或自行整理后方可在新位置读取。：计算事实与边界

结果均为软件示例模型的计算，不是现场测量；本材料不包含标准修订内容。扫描定义在 `cases/studies/`；结果在本地 `build/parameter-sweep/`，CSV、XLSX、DOCX 和逐样本 SQLite 可由所附定义重建。

## 共用竖井

3 种层数、3 种宽度、3 种深度、3 种同时使用率、2 种风机曲线与 3 种阀等级交叉，共 486 组。为保证底层参与，使用楼层分布固定为低层集中；宽度与深度独立组合，构成 9 种截面。竖井及支管等温、稳态，支管尺寸、井壁粗糙度、阀泄漏、屋顶开口和住户气密性采用模型默认假设，风机为理想曲线，并非实测。逐层计算没有考虑动态烹饪、用户同步随机变化、风机实测曲线或现场反馈。

所计算的底层运行风量范围约 154.802～750.857 m³/h；以 300 m³/h 作为本研究的数值比较线，486 组中达到该值的比例约 89.095%。该比例由本次人工设置的组合均权形成，不代表实际住宅的统计概率。最不利运行层、最大倒灌指标和各因子分组的逐样本结果见 `build/parameter-sweep/shaft-study/`。二维分组输出 `竖井分组表.csv`、`竖井分组表.docx`。

## 户内补风

n₅₀ 四档、排风量三档及两种卧室数，共 24 组；使用固定 250 m³ 住宅、封闭厨房、150 m³/h 新风送风、127.5 m³/h 新风排风，其他门缝、过流口和围护分配采用模型默认假设。机械与自然补风分别单独反算，目标为厨房相对室外 −15 Pa；这是示例提示线，不是燃气安全限值。机械补风约 9.856～311.692 m³/h，自然补风口有效面积约 9.126～288.603 cm²。按 n₅₀、排风量和两卧/三卧组织的二维表为 `build/parameter-sweep/makeup-study/补风二维表.csv`、`补风二维表.docx`。

## 可复核性

每个目录包含逐样本 CSV/XLSX、`samples.sqlite3` 中的完整输入和溯源、`statistics.json` 与 DOCX 汇总；`tools/check_study_samples.py` 对两类各三个样本独立调用 CLI 比较，`tools/check_study_statistics.py` 独立从 CSV 重算分位数、组均值、达标率和主效应极差。两个示例的模型、假设和参数范围均由输入定义，不构成推广到真实建筑群体的证据。
