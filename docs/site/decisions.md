# 决策记录

## 计算内核

数值计算独立于用户界面，内核统一使用 SI；工程单位在输入输出层换算。每次执行记录版本、输入哈希和适用规则版本，参数需有来源或明确标为假设。

## 外部程序对照

多区域压力网络以自研求解为主，独立程序作为有限范围的交叉验证。只映射已核实的物理元件；无法等价映射的连接明确拒绝，不能将同一错误实现的互相吻合当成验证。外部强著作权许可程序只能作为独立进程调用，不随软件分发。

## 依赖与数据

优先采用许可清晰的依赖并保留许可证声明。数据不足时优先采用已发表数值或标注精度的读图；仍不足时使用有敏感性分析的假设，不为贴合目标调参。气象、标准原文和第三方二进制不随软件分发。自动检查与数值验证不能代替法定审查、现场安全确认或负责人复核。
