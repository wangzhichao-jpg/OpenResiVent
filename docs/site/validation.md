# 验证报告

## 解析基准

数值基准覆盖二氧化碳稀释、热压、孔口、管道摩擦、空气龄及设备效率。基准检查特定公式与输入，不代表所有工况已验证。活塞流通道以长度3 m、均匀速度0.5 m/s为解析值；二阶通道单元中心除首排外最大相对偏差约0.418%。

## 多区域独立对照

非等温真实孔口的三个数值工况逐路径质量流量偏差小于0.03%；模型使用明确的面积、流量系数、温度与压力边界。其他元件的非等温映射及小压差线性分支不可由此推定等价。污染物时间序列受两种时间积分方法影响，比较时应明确时间步和浓度转换。

## 竖井与热回收趋势

竖井计算展示楼层、截面、使用率及阻力对压力和倒灌的影响；矩形、非等温和现场实际建筑的误差仍须独立核查。滤网积尘、热交换和结霜采用文献表格或图中估计值，超出试验范围不作为定量验证；不同测量边界的节能率不能直接混用。

## 通风能耗趋势

天气数据逐时驱动热负荷及风机计算，仅比较新风处理和风机电耗。理想调速可低于节流控制功率，但不包含变频器低速损失；自然冷却潜力须受建筑实际冷负荷和运行时间限制。外部气象文件不随软件分发，来源及许可应由使用者核实。

## 室内空气龄数值检验

室内三网格比较必须先证明流场和标量的迭代收敛，再评估空间离散误差。一阶格式的网格收敛不证明二阶格式或物理模型的准确性。二阶房间算例在流场及标量满足监测门槛后，三网格呈振荡；按三网格效率半极差估算的相对细网格不确定度分别约0.86%和1.38%。该指标不涵盖湍流模型、均匀有效扩散及热浮力的误差；任何计算结果均不能代替现场检测或实验。
