# 下载与安装

公开测评源码可从 [GitHub 仓库](https://github.com/wangzhichao-jpg/OpenResiVent)或 [Gitee 仓库](https://gitee.com/bigtaurus/OpenResiVent)获取。当前公开测评版本为 v0.5.0rc2（2026-11-09），安装包见两站仓库的“发行版”（Releases）页面，以页面实际显示为准。

## 从发行附件安装

当发行页面提供 wheel 与校验信息后，下载与自己 Python 版本兼容的 wheel，先核对发布方提供的 SHA256；校验通过后在 Python 3.11 或更新版本的虚拟环境安装：

```bash
python -m venv .venv
. .venv/bin/activate
python -m pip install -i https://pypi.tuna.tsinghua.edu.cn/simple ./openresivent-0.5.0rc2-py3-none-any.whl
resivent --version
resivent serve
```

上述文件名是 v0.5.0rc2 示例；其他版本应使用附件实际名称。Windows 请使用 `.venv\Scripts\activate`。清华镜像仅用于解析 Python 依赖；轮子文件来自用户核验的发行附件，不关闭 TLS 校验。

## SHA256 校验

Linux 可对单个文件运行 `sha256sum 文件名`，或在校验文件所在目录运行 `sha256sum -c SHA256SUMS.txt`；Windows PowerShell 可运行 `Get-FileHash 文件名 -Algorithm SHA256`。把结果与可信发行页面的同名文件哈希逐字比较，不一致时不要安装。各版本安装包的 SHA256 以发行页面所附 `SHA256SUMS.txt` 为准；哈希只对应相应版本的发布构建物，不适用于其他版本或重新打包的文件。

## 从源码安装

以已下载的公开源码目录为当前目录，先构建前端，再安装 Python 包：

```bash
npm ci --prefix web --registry=https://registry.npmmirror.com --no-audit --no-fund
npm run build --prefix web
python -m venv .venv
. .venv/bin/activate
python -m pip install -i https://pypi.tuna.tsinghua.edu.cn/simple .
resivent --version
resivent serve
```

源码安装需要 Node.js 和 npm；锁文件用于固定前端依赖，不能跳过完整性校验。也可在安装前使用 `python -m pip install ... build` 和 `python -m build` 构建自己的 wheel，但本地构建物的哈希应独立记录。`resivent desktop` 需要可选窗口组件，未安装时使用浏览器；此处不提供预打包桌面发行件。服务默认只监听本机且无认证，请勿直接暴露到公网。
