# 浏览器本地计算原型

本原型仅供本地构建和测试，不是已部署的在线服务或正式发行版。支持新风量、户内压差与补风反算、高层竖井；DOCX 报告、参数扫描、CFD 和外部程序对照须切换本机服务或命令行。示例和假设不替代现场检测或安全评估。

## 本地构建与预览

在源码目录预先通过配置好的可信镜像安装前端依赖，并运行下列命令。准备运行时需要网络，仅构建时下载；下载文件按固定的运行时锁文件 SHA256 检验。浏览器计算时加载本机构建的文件：

```bash
npm ci --prefix web
python tools/prepare_browser_runtime.py
npm run build --prefix web
npm exec --prefix web -- vite preview --host 127.0.0.1
```

运行 `python tools/prepare_browser_runtime.py --dry-run` 可只查看准备计划，不下载或写入；`--help` 显示选项。下载中断或校验失败时会有限次数退避重试，每次重新校验哈希。

Node 一致性测试默认使用项目的 `.venv/bin/resivent`；其他环境可设置 `ORV_CLI=/绝对路径/resivent` 后运行 `npm run verify:browser --prefix web`，指向与源码同版本的命令行程序。该测试禁止网络请求。

打开预览程序在终端显示的本机地址，切换“浏览器本地计算”。首次加载需要下载本机静态资源，大小取决于构建版本，之后由浏览器自行缓存；本项目不收集或上传算例。界面以本地 Python WebAssembly 内核运算，输入保留在浏览器；本机服务模式则由用户主动将算例提交给本机服务。不要将无认证的预览服务暴露到公网。

## 安全与限制

网页及本机服务的内容安全策略保留同源限制；为 WebAssembly 增加 `script-src 'wasm-unsafe-eval'`，不启用通用 `'unsafe-eval'`。原版运行时含上游默认远程回退字符串；加载器在加载包前强制指定本地目录，页面连接与脚本来源限定本机同源。扫描器只按原版文件路径、SHA256 和具体地址的完整组合放行两处已知字符串；文件或地址变化时须重新审核，其他外部请求不放行。

Node 环境通过禁止网络的本地计算对照。一般数值项按严格相对误差比较；接近零的质量守恒残差仅按明确命名字段检查绝对误差，且两侧必须满足各自的求解收敛判据。此对照不等于真实浏览器体验验证，也不等于现场验证；不得未经授权部署。
