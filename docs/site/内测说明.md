# 住宅通风计算软件测评说明

当前公开测评版本为 0.5.0rc2（2026-11-09），安装附件见[下载与安装](下载与安装.md)。测评版本并非经过产品认证的正式设计软件。

## 安装与启动

需要 Python 3.11 或更新版本。取得本地 wheel 后，在新建虚拟环境中执行：

```bash
python -m venv .venv
. .venv/bin/activate
python -m pip install /本地路径/openresivent-0.5.0rc2-py3-none-any.whl
resivent --version
resivent serve
```

访问终端显示的本机地址。`resivent desktop` 使用可选桌面窗口组件；未安装时回退到默认浏览器。Windows 用户可用虚拟环境的 `Scripts` 目录激活脚本。服务默认监听 `127.0.0.1` 且无认证，请勿直接暴露公网。示例命令和扫描说明见[用户手册](user.md)。

## 已验证功能与局限

新风量、基础物性、部分多区域网络、竖井、水力、户内压差、检测数据处理及参数扫描均有解析或数值回归；部分工况经外部模型对照。实际验证范围和数值参见[验证说明](validation.md)。通过自动测试不等于所有工况已验证。

气象文件和外部流场或多区域计算程序不随软件分发；缺少这些资料时相关测试可能跳过。图形参数扫描可编辑数值阈值判据，规则包判据请用命令行；任务状态在服务重启后消失，已有样本可用命令行续算。风管声学完整路径尚无完全等价的公开全路径对照。计算结果不替代现场检测、安全评估或设计审查。

## 示例与假设

示例风机曲线、风管噪声频谱和衰减、户型气密性、竖井边界、运行率、产品参数及部分气象工况是示例或假设，不应视作任意实际项目的实测数据。扫描结果取决于所选范围；等权参数组合中的达标比例不是建筑群体的实际概率。户内负压示例的 15 Pa 只是提示阈值，不是燃气安全限值。
