# 用户手册

## 一户完整校核

在本机服务模式选择“一户校核”，依次检查户型、新风量、压差与补风、可选噪声、条文汇总和报告六步。可前后跳转；输入变化后相关结果会标记“需重新计算”，需重新计算后再下载合并 DOCX。补风反算使用封闭厨房、默认门缝及过流口、起居室送风和厨房补风，与可配置前向方案的边界可能不同。输入可导出 JSON 再导入；示例均为假设，须核实。

命令行也可执行同一份 JSON/YAML：

```bash
resivent check cases/workflows/household_example.yaml --out build/household-check
```

输出 `result.json` 和 `report.docx`。一户合并报告目前需要本机服务或命令行，浏览器模式提示切换。该流程的时间取决于数据准备情况，未开展用户耗时测试。

## 批量扫描

界面选择“参数扫描”，选择竖井或户内补风，勾选因子并填写离散水平或连续范围；选择全因子或拉丁超立方、输入种子和样本数，再选择指标及可选的数值阈值。开始后显示进度，完成后显示统计、分组达标率、敏感性条形图，并可下载 CSV、XLSX、DOCX。定义可用 YAML 导入导出；命令行使用导出的定义时，相应基准算例文件须位于定义文件同一目录。界面暂不编辑规则包判据。退出扫描页不会取消后台作业，同一浏览器会话可返回查看；服务重启后需通过命令行续算。

`resivent sweep cases/studies/makeup_sweep.yaml --out /绝对路径/扫描结果 --workers 2`；YAML 指定基准算例、因子、全因子或带种子的拉丁超立方、结果路径和可选上下限/公开规则。输出 CSV、XLSX、统计 JSON、DOCX 和含完整输入及溯源的 SQLite；再次执行相同定义可续算。输出目录使用锁，修改输入、程序源码或规则版本后不能续用旧目录。全因子报告主效应极差；拉丁超立方报告标准化秩回归系数；文本分类按输入给出的水平顺序编码，系数随人为顺序变化，不能解释为天然连续量；敏感性表可作为龙卷风图数据。分组结果为离散水平的均值和达标率，结果为模型计算，不替代现场核查。

本机 API `POST /sweep` 接收 `case`、`spec`、可选单级子目录名 `out` 与 `workers`，返回任务号；`GET /sweep/{任务号}` 查询进度。默认扫描根目录是用户目录 `.local/share/openresivent/sweeps/`，可以通过环境变量 `ORV_SWEEP_DIR` 修改，未指定子目录名时采用随机名称。API 不接受绝对路径、路径分隔符及符号链接；命令行的输出目录不受此限制。任务状态保存在服务进程中，服务重启后任务号不可查询；可用同一目录和定义在命令行续算。无认证服务只能供可信本机使用，不应对外开放。

## 卧室噪声初筛

全户新风量界面可选启用卧室噪声初算，输入 63 Hz 至 8 kHz 风机八频带声功率级、距离和房间常数；直管、弯头、消声器、末端反射及再生声频谱可在算例编辑区修改。示例数据与风量指数均为假设，需以检测数据核实。结果显示不同风量下 A 声级和给定目标的反算最大风量，单一路径预测不能代替背景声、结构传声及现场验收。

## 书稿正文与完整演算

在源码项目根目录执行 `python tools/render_book.py`，生成 `build/book_fragments/chNN/` 正文及 `build/book_appendix/chNN_完整演算.md`，每章附录含原完整过程和全精度结果。气象及 CFD 算例需要各自的外部输入，未提供时工具明确报错；不提供现场数据或自动下载。再执行 `python tools/pending_sources.py` 生成 `build/待确认参数清单.md`。这些文件是本地构建产物，不修改原书稿；出版前需作者核实来源与表述。完整演算可在配置所需外部输入后于本地生成。

算例包含 `meta`、`module`、`input`、`output`；工程量输入按算例字段所示单位，内核统一采用 SI。可从 `cases/book/` 选择示例，替换户型、风量和温湿度等输入。计算结果含输入哈希、版本及规则包信息。

| 功能 | 主要输入 | 输出和限制 |
|---|---|---|
| 新风量 | 居住面积、人数、室内外浓度 | 需求风量；污染源及占用需核实 |
| 多区压力 | 节点温度、连通路径、开口与风机 | 压力和路径流量；稳态、充分混合 |
| 竖井与户内压力 | 层数、管道、风机、气密性、补风方案 | 逐层流量、压力和提示；不构成燃气安全判定 |
| 热回收与能耗 | 气象、风量、效率、控制方案 | 小时负荷和能量；不等同整栋建筑动态模拟 |
| 现场验收 | 监测记录、设计和实测风量 | 分别列出设计轨与验收轨；采样条件需现场核查 |
| 空气龄模拟 | 房间、开口、风量与网格 | 依赖独立安装的外部求解程序；不能以数值收敛代替现场验证 |

## 命令和报告

报告命令 `resivent report 算例.yaml --format docx`；专题报告另选 `--type shaft` 或 `--type commissioning`。专题算例组合竖井及住宅压力，或组合监测记录和运维参数；结果仅为自查，不是检测证明。竖井与住宅工况不是联立流场。

## 本机 API

API 接收与算例相同的 JSON 对象，仅开放不需要用户提供外部文件路径的模块。`POST /run` 返回计算及溯源；`POST /report?type=design`、`?type=shaft` 和 `?type=commissioning` 返回 DOCX。错误输入返回 422；`GET /rules` 返回标准、条文、强度和转述。临时文件只保留到请求完成；服务默认仅本机监听，不含身份认证。

## 常见输入与解释

- `co2`：`occupants`、`co2_l_h_person`、`co2_outdoor_ppm`、`co2_limit_ppm`；输出 `flow_m3_s`。限值须高于室外背景。
- `ventrate`：输入户型面积、净高、人数、卧室和起居室；输出各路径、房间和全户风量以及适用条文初筛。
- `dwelling_pressure`：输入卧室数、气密性、设备风量、补风位置与提示阈值；输出各房间压力与方案对比。该阈值不是安全合格限值。
- `ductless`：设备额定风量与有效换气率相乘，比较房间需求；有效换气率须来自适用工况的测量。
- `product_test`：输入干空气质量流量、温湿状态、风机工况和颗粒物一次通过效率；输出交换效率、比功率及净化能效。
- 专题报告输入的竖井尺寸与监测序列须核对单位、时标及隐私；提供逐条监测数据时使用 ISO 时间和 SI 浓度。

气象年度计算和 CFD 结果读取依赖外部文件，不通过 API 白名单开放；应在明确路径和许可条件下使用命令行。所有自动判定都应结合现场数据、标准适用性和人工复核。
